# v2.5 — UI 重设计（借鉴 OpenRouter）

## 目标

把当前"够用但偏工程感"的深色单主题界面，升级为对标 OpenRouter 的现代、数据前置、
可信赖的产品级视觉。核心是：**模型目录成为一等公民、明暗双主题、更精炼的设计系统、
数据驱动的首页**。

---

## 一、OpenRouter 设计语言拆解（我们要借鉴什么）

| 特征 | OpenRouter 做法 | 我们借鉴 |
|---|---|---|
| **数据前置** | 首页大数字：100T tokens / 10M 用户 / 70+ 供应商 / 400+ 模型 | 首页展示真实统计：可用模型数、渠道数、累计请求/tokens |
| **模型目录** | 招牌页 `/models`：可搜索、按价格/热度排序、供应商图标、上下文长度 | 新增 `/models` 目录页，从 `/public/*` 拉真实数据 |
| **明暗双主题** | 默认浅色、可切深色，都很克制 | 加 light/dark 切换，默认跟随系统 |
| **精炼排版** | 大量留白、清晰层级、等宽字体点缀技术元素 | 收紧间距体系、统一字号阶梯、卡片更轻 |
| **热度/趋势** | 模型带周趋势 +14% / -5% | 模型目录/首页展示"热门模型"（按用量排行） |
| **可信任元素** | 供应商 logo 墙、正常运行时间、数据政策 | 特性区突出"多渠道故障转移/加密存储/可对账计费" |

## 二、设计系统升级

### 主题：明暗双色

```
亮色（默认，OpenRouter 风）        暗色（保留现有深色）
--bg     #fafafb / #ffffff        #0b0d13
--panel  #ffffff                  #151925
--border #e6e8ee                  #262d3d
--text   #1a1d26                  #e8eaf0
--muted  #6b7280                  #98a1b3
主色     #4f46e5(靛蓝) 强调 #0ea5e9(天蓝)
```

- 用 CSS 变量 + `data-theme` 属性切换，`localStorage` 记忆，默认 `prefers-color-scheme`。
- 主色从"靛蓝+青渐变"收敛为更克制的**靛蓝主色 + 少量渐变仅用于 CTA/Logo**（OpenRouter 很少大面积用渐变）。

### 排版与间距

- 字号阶梯：`12/13/14/16/20/28/44`，统一行高。
- 间距用 4 的倍数（8/12/16/24/32/48/72）。
- 卡片：更细边框、更小圆角（10-12px）、hover 微阴影而非位移。
- 引入细节：字重对比（标题 700 / 正文 400 / 标签 500）。

### 组件标准化

统一：按钮（primary/secondary/ghost/sm/lg）、卡片、表格、标签(pill)、
搜索框、下拉、开关、代码块、空状态、骨架/加载态、toast。

## 三、页面改造

### 1. 首页 `/`（数据前置）
- Hero：更克制的标题 + 一句话价值主张 + 双 CTA（获取 Key / 浏览模型）。
- **实时统计条**：模型数 / 渠道数 / 累计请求（拉 `/public/*` 与新增的公开 stats）。
- 供应商/模型 logo 墙。
- 特性区（3-6 张）：故障转移、按量计费、多协议、可观测。
- 快速上手代码块。

### 2. 模型目录 `/models`（新增，招牌页）
- 顶部搜索框 + 排序（价格/名称/热度）。
- 模型卡片/行：模型名、所属类型、输入/输出价、（可选）上下文、热度。
- 数据来自 `/public/models` + `/public/pricing`（已有）。
- 点击展开该模型的调用示例。

### 3. 文档 `/docs`、价格 `/pricing`
- 套用新设计系统，排版精炼；价格页可与模型目录风格统一。

### 4. 控制台 `/portal`、后台 `/admin`
- 套用新主题（明暗）与组件；布局逻辑不变，仅视觉刷新。
- 后台侧边栏化（可选）：把顶部一排 Tab 改为左侧导航，更像 SaaS 控制台。

---

## 四、公开数据端点（首页/模型页要用）

现有：`GET /public/models`、`GET /public/pricing`、`GET /public/settings`。
新增：`GET /public/stats` —— 对外安全的聚合数字（模型数、渠道数、累计请求数），
不含任何敏感信息（复用 usage.stats 的 total.requests + 计数）。

---

## 五、技术实现（保持零构建）

- 继续纯内联 HTML/CSS/JS，不引前端框架/构建链。
- 设计系统集中在 `shared.py`：CSS 变量双主题 + 主题切换 JS + 组件类。
- 各页面只改结构与类名，逻辑（fetch/i18n）复用。
- 新增 `site_models.py`（模型目录页）。

## 六、不做（本版边界）

- 不引入 React/Vue/构建工具（保持可随后端一起部署）。
- 不做复杂图表库（趋势图仍留后续；本版聚焦风格与模型目录）。
- 不改任何后端业务逻辑与数据库。
