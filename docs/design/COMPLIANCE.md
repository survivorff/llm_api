# 合规说明 (COMPLIANCE)

> 本文件面向**部署者**。本项目仅提供开源软件工具，不提供任何 LLM 服务本身，也不代收代付任何款项。

## 重要声明

- 本项目仅适用于**合法且已授权**的 API 网关、组织内鉴权、多模型管理、用量统计、成本核算与私有部署场景。
- 部署者必须**合法获取**上游 API key、账号、模型服务与接口权限，并遵守上游服务条款与所在司法辖区的法律法规。
- 多数上游服务商（OpenAI / Anthropic / Google 等）的服务条款**明确禁止转售**其 API。将本网关用于对外经营/转售前，请自行确认已获授权。

## 面向公众提供生成式 AI 服务时，部署者需自行完成（按辖区要求）

- 备案 / 经营许可（如增值电信业务许可等）
- 内容安全审核接入
- 用户实名认证（KYC）
- 日志留存与可追溯
- 税务登记与合规开票
- 上游服务授权确认

## 支付相关风险

- 本项目的支付能力以**可插拔适配器**形式提供，部署者自行选择并接入。
- 无 / 弱 KYC 的支付方式（个人收款码、易支付聚合等）存在被用于洗钱、"跑分"的风险，可能导致账户与资金被冻结。
- 选择任何支付方式的合规与资金风险，由部署者自行承担。

## 责任边界

- 项目作者与贡献者**不对**部署者的任何使用行为、由此产生的法律/合规/资金后果承担责任。
- 使用本项目即表示部署者理解并接受上述条款。
