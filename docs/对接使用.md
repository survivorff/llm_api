# 对接使用文档（发给朋友的就是这份）

> 你拿到的是一个 **OpenAI 兼容** 的 API 网关。任何支持"自定义 OpenAI 接口"的工具都能接。
> 你只需要两样东西：**Base URL** 和 **API Key**（管理员发给你的 `sk-...`）。

## 0. 你会拿到
- Base URL：例如 `https://你的域名/v1` 或 `http://服务器IP:8080/v1`
- API Key：`sk-xxxxxxxx`（请妥善保存，不要外传）
- 可用模型名：如 `deepseek-chat`、`claude`、`gpt` 等（以管理员告知为准）

## 1. 在 Cursor 里用
设置 → Models → 选 OpenAI → Override Base URL：
- Base URL：`填上面的 Base URL`
- API Key：`你的 sk-...`
- 添加模型名：`deepseek-chat`（日常）/ `claude`（攻坚）
保存后在对话框选对应模型即可。

## 2. 在 Cline / Roo（VSCode 插件）里用
API Provider 选 **OpenAI Compatible**：
- Base URL：`Base URL`
- API Key：`你的 sk-...`
- Model ID：`deepseek-chat` 等

## 3. 在 Aider（命令行）里用
```bash
export OPENAI_API_BASE="你的 Base URL"
export OPENAI_API_KEY="你的 sk-..."
aider --model deepseek-chat
```

## 4. 用 curl 测试
```bash
curl 你的BaseURL/chat/completions \
  -H "Authorization: Bearer 你的sk-..." \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"你好"}]}'
```

## 5. 用 Python（openai SDK）
```python
from openai import OpenAI
client = OpenAI(base_url="你的BaseURL", api_key="你的sk-...")
resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```

## 6. 查自己的用量 / 剩余额度
```bash
curl 你的BaseURL/me -H "Authorization: Bearer 你的sk-..."
```
返回里有 `used_tokens`（已用）、`remaining_tokens`（剩余）、`expires_at`（到期）、`rpm_limit`（限速）。

## 7. 看模型清单
```bash
curl 你的BaseURL/models -H "Authorization: Bearer 你的sk-..."
```

## 常见问题
- **401**：key 错了 / 被停用 / 已过期 → 找管理员。
- **403**：这个模型不在你的可用范围 → 换模型或找管理员开通。
- **429**：要么超了配额（剩余=0），要么触发了限速（RPM）→ 稍等或找管理员加额度。
- **404 no channel for model**：模型名写错了 → 用 `/models` 看支持哪些。
- **502**：上游临时故障，稍后重试。
