# 使用前要准备什么（给管理员/你自己）

> 按"只给自己本地用 → 给朋友远程用"两个阶段列。先看你处于哪个阶段。

## 阶段 A：只在本地自己用（最简单）

只需准备 **上游模型的 API key**，填进 `.env`：

| 上游 | 怎么获取 | 付款 | 备注 |
|---|---|---|---|
| DeepSeek | platform.deepseek.com 注册建 key | 人民币，无门槛 | 日常编码主力，便宜 |
| 通义千问(Qwen) | 阿里云百炼 DashScope 控制台 | 人民币 | 国产备选 |
| OpenRouter | openrouter.ai 注册建 key | **支持加密货币充值**（绕开外卡）| 调 Claude/GPT/Gemini |
| OpenAI 官方 | platform.openai.com（需外卡）| 美元外卡 | 有外卡才填 |

> 只填你有的；留空的渠道会自动禁用。**至少填 1 个**（建议先 DeepSeek，立刻能用）。

其它：本机有 Python 3.10+（你已是 3.14）即可，`bash run.sh` 自动建环境。

## 阶段 B：放到服务器、给朋友用（要多准备几样）

### 1. 一台服务器
- 推荐**境外/香港/新加坡节点**（阿里云国际版、轻量应用服务器等）。
- ⚠️ **关键网络问题**：阿里云**国内**节点**直连不了** OpenRouter / OpenAI / Anthropic。
  - 只用国产模型（DeepSeek/Qwen）→ 国内节点就行。
  - 要给朋友用 Claude/GPT → **必须用境外节点**，或在国内节点上配置到境外的转发出口。
- 配置：1-2 核 2G 起步够用（网关本身很轻，瓶颈在上游）。

### 2. 域名 + HTTPS（强烈建议）
- 一个域名，解析到服务器。
- 用 Nginx + Let's Encrypt 配 HTTPS（朋友的工具大多要求 https，且避免 key 明文传输）。
- 没有域名也能用 `http://IP:8080`，但不安全、不推荐对外。

### 3. 两个强随机密钥（必须改）
在服务器 `.env` 里设置（别用默认值）：
```
ADMIN_KEY=<openssl rand -hex 16 生成>
GATEWAY_KEY=<openssl rand -hex 16 生成>
```

### 4. Docker（推荐部署方式）
- 服务器装 Docker + docker compose。
- `docker compose up -d --build` 即可，`config.yaml` 和 `.env` 挂载进去。

### 5. 给每个朋友定好策略（你来决定）
- 配额（多少 token）、有效期（多少天）、限速（RPM）、可用模型。
- 在 `/admin` 后台逐个建令牌，把 `sk-...` + `docs/对接使用.md` 发给他们。

### 6. 安全 / 合规自查
- `/admin` 后台加 IP 白名单（只允许你自己访问）。
- Nginx 加基础限流，防止被刷爆上游账单。
- **不要公开售卖/转售**（涉及备案、内容安全、上游授权、税务等义务）——朋友间互助不踩这条线。

## 一句话清单
- 本地自用：填 1 个上游 key（先 DeepSeek）→ `bash run.sh` → 完事。
- 给朋友用：境外服务器 + 域名HTTPS + 改两个密钥 + Docker 部署 + 后台建令牌 + 发对接文档。
