# 本地部署与使用全流程

> 从零开始：在本机把网关跑起来 → 后台建令牌 → 在 Cursor 等工具里用上。
> 跟着 7 步走，全程约 15 分钟。

---

## 全流程总览

```
①准备环境  →  ②拿上游 key  →  ③配 .env 和 config  →  ④启动
                                                          │
                                                          ▼
⑦在工具里用 ← ⑥后台建令牌(给自己/朋友) ← ⑤验证服务正常
```

- **后台**（你做）：配置 + 启动 + 在 `/admin` 创建分发令牌。
- **前台**（你和朋友）：拿到 `sk-...`，填进 Cursor/Cline 等工具调用。

---

## 第 0 步：先搞清楚两类密钥（不要混）

| 名称 | 在哪设 | 干嘛用 | 给谁 |
|---|---|---|---|
| `ADMIN_KEY` | `.env` | 登录 `/admin` 后台、建/删令牌 | 只有你自己 |
| `GATEWAY_KEY` | `.env` | 你自己调用网关（owner，免配额） | 只有你自己 |
| 朋友令牌 `sk-...` | 后台动态生成 | 朋友调用网关 | 发给每个朋友 |
| 上游 key（DeepSeek 等）| `.env` | 网关去调真正的模型 | 不外传，只在服务器 |

> 一句话：上游 key 是"网关的成本来源"，藏好；朋友令牌是"你分发出去的门票"，可随时收回。

---

## 第 1 步：准备环境

- 本机已装 **Python 3.10+**（你是 3.14，OK）。
- 拿到代码（已在 `~/ai/kiro/ai_learn/llm_api`）。
- 不用手动装依赖，`run.sh` 会自动建虚拟环境。

---

## 第 2 步：拿至少一个上游 API key

**最低要求：先搞定 1 个就能用。** 推荐顺序：

1. **DeepSeek（最推荐先用）**
   - 去 platform.deepseek.com 注册 → 创建 API key。
   - 人民币充值，无门槛，编码够强够便宜。
2. **通义千问 Qwen**（可选）
   - 阿里云百炼 / DashScope 控制台创建 key。
3. **OpenRouter（想用 Claude/GPT）**
   - openrouter.ai 注册 → 创建 key。
   - **支持加密货币充值**，绕开外卡难题。
4. **OpenAI 官方**（有外卡才需要）。

---

## 第 3 步：配置 `.env` 和 `config.yaml`

```bash
cd ~/ai/kiro/ai_learn/llm_api
cp .env.example .env          # 如果还没有
cp config.example.yaml config.yaml   # 如果还没有
```

编辑 **`.env`**，填上你的密钥：
```
ADMIN_KEY=自己设一个复杂点的           # 后台密码
GATEWAY_KEY=sk-自己设一个              # 你自己用的 key
DEEPSEEK_API_KEY=sk-xxxx              # 你第 2 步拿到的
OPENROUTER_API_KEY=                   # 没有就留空
QWEN_API_KEY=
OPENAI_API_KEY=
```

`config.yaml` 一般**不用改**：留空 key 的渠道会自动禁用，你只填了 DeepSeek 就只有 DeepSeek 生效。
> 想加模型/改别名时再看 `config.yaml` 里的 `channels` 与 `model_map`。

---

## 第 4 步：启动

```bash
bash run.sh
```
- 首次会自动建 venv、装依赖，然后启动。
- 默认监听 `http://127.0.0.1:8080`。
- 想换端口：`PORT=9000 bash run.sh`。
- 停止：在终端按 `Ctrl+C`。

---

## 第 5 步：验证服务正常

```bash
curl http://127.0.0.1:8080/healthz
```
返回 `{"status":"ok","channels":["deepseek", ...]}`。
- `channels` 里应能看到你填了 key 的渠道。**如果是空的，说明 `.env` 里上游 key 没填或没生效**（检查后重启）。

---

## 第 6 步：进后台建令牌

1. 浏览器打开 **http://127.0.0.1:8080/admin**
2. 输入你在 `.env` 设的 `ADMIN_KEY`，点进入。
3. 点 **＋ 新建令牌**，填：
   - 名称（如"我自己""张三"）
   - 配额 tokens（留空 = 无限；给朋友建议设个上限，如 200000）
   - 有效天数（留空 = 永久；给朋友可设 30）
   - 限速 RPM（留空 = 不限；防止被刷，可设 60）
   - 允许模型（留空 = 全部；可只给 `deepseek-chat`）
4. 保存后系统会**自动复制**生成的 `sk-...`，发给对应的人。
5. 之后可随时在列表里**启停/编辑/删除**，并看每个人用了多少。

> 你自己用也可以直接用 `.env` 里的 `GATEWAY_KEY`，不必建令牌（owner 免配额）。

---

## 第 7 步：在工具里用（前台）

通用三要素：
- **Base URL**：`http://127.0.0.1:8080/v1`
- **API Key**：你的 `GATEWAY_KEY` 或后台发的 `sk-...`
- **Model**：`deepseek-chat`（日常）/ `claude`（若配了 OpenRouter）

### Cursor
设置 → Models → OpenAI → Override Base URL 填 `http://127.0.0.1:8080/v1`，API Key 填你的 key，添加模型名 `deepseek-chat`。

### Cline / Roo（VSCode 插件）
Provider 选 **OpenAI Compatible**，Base URL + API Key + Model ID 同上。

### 命令行验证
```bash
curl http://127.0.0.1:8080/v1/chat/completions \
  -H "Authorization: Bearer 你的key" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"你好"}]}'
```

### 查自己用量
```bash
curl http://127.0.0.1:8080/v1/me -H "Authorization: Bearer 你的key"
```

> 更详细的对接说明（发给朋友的版本）见 [对接使用.md](./对接使用.md)。

## 常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| healthz 的 channels 为空 | 上游 key 没填/没生效 | 检查 `.env`，重启 |
| 调用返回 401 | key 错/停用/过期 | 核对 key，或后台启用 |
| 403 | 该模型不在令牌白名单 | 换模型或后台放开 |
| 429 | 超配额 或 触发 RPM 限速 | 后台加额度 / 稍等 |
| 404 no channel for model | 模型名不对 | `curl /v1/models` 看支持哪些 |
| 502 | 上游报错/网络不通 | 看终端日志，确认上游 key 有效、网络可达 |
| /admin 打不开或一直要密钥 | ADMIN_KEY 不对 | 核对 `.env` 里的 `ADMIN_KEY` |

> 注意：本机直连 OpenRouter/OpenAI/Anthropic 需要你的网络能访问境外。纯 DeepSeek/Qwen 无此问题。
